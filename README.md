# FITСтудент — готовая версия проекта

Клиентское веб-приложение на HTML, CSS и JavaScript. Без аккаунта, API-ключей и внешних библиотек.

## Что сделано
- Переключение русского и английского интерфейса.
- Три программы: спина и офис, кардио, силовая. В каталоге — 45 упражнений.
- Каждый день стабильно выбираются 4 упражнения на категорию.
- У каждого упражнения — иллюстрация в двух кадрах (исходное / конечное положение).
- Виджет воды с анимированным стаканом.
- Прогресс, вода и выбранная программа сохраняются в `localStorage`.
- Service Worker для офлайн-работы.
- Нет внешних запросов; приложение не передаёт данные на сервер.

## Иллюстрации

Иллюстрации упражнений — из открытого проекта [Everkinetic](https://everkinetic.com), лицензия CC-BY-SA 4.0.

Файлы лежат в папке `illustrations/` и называются по ID Everkinetic:
- `{id}-relaxation.svg` — исходное положение
- `{id}-tension.svg` — конечное положение

Маппинг «ID упражнения → ID иллюстрации Everkinetic» находится в `exercise-illustrations.js` в объекте `FRAMES`.

## Как поменять иконку и логотип

Редактируйте только `brand-config.js`:
- `logoUrl` — путь к вашей иконке.
- `logoFallback` — эмодзи, если картинка не загрузится.
- `logoSize` — размер логотипа в шапке.
- `themeColor` / `bgColor` — цвета.
- `brandName` / `brandNameAccent` / `brandTagline` — текст бренда.

## Как устроен каталог упражнений

Файл `exercise-bank.js` содержит два каталога: `FIT_BASE_EXERCISES` и `FIT_EXTRA_EXERCISES`. У каждого упражнения есть `id`, `frameId` (ключ иллюстрации), название, дозировка, описание и предупреждение.

Чтобы добавить упражнение:
1. Добавьте объект в нужную категорию в `FIT_EXTRA_EXERCISES`.
2. Укажите уникальный `id` и `frameId` из существующих ключей в `exercise-illustrations.js`.
3. Заполните `name`, `dose`, `description`, `safety` для `ru` и `en`.

## Как запустить

### Быстрый просмотр
Откройте `index.html` в браузере. Service Worker работает только через `localhost` или HTTPS.

### Полный режим с офлайн-кэшем
1. Установите Python 3.
2. `python -m http.server 8000`
3. Откройте `http://localhost:8000`.

Для публикации разместите папку на статическом хостинге с HTTPS (GitHub Pages и т.п.). При обновлении файлов меняйте `CACHE_NAME` в `sw.js`.
