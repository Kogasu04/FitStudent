# FITСтудент

Интерактивный лендинг для отслеживания тренировок и потребления воды. 
Простой пет-проект на чистом HTML, CSS и JavaScript.

## Что уже есть

- Карточки со статистикой
- Выбор цели тренировки
- Чек-лист упражнений с плавной сменой при выборе цели
- Трекер воды с визуальным стаканом
- Адаптивная верстка

## Стек

- HTML5
- CSS3 (Grid, Flexbox, анимации)
- Vanilla JavaScript (ES6+)
- Без фреймворков и библиотек

## Планы

- **Backend** для хранения данных о тренировках за несколько дней
- История тренировок и статистика по неделям
- Сохранение прогресса между сессиями (LocalStorage → БД)
