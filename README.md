# FITСтудент — готовая версия проекта

Клиентское веб-приложение на HTML, CSS и JavaScript. Без аккаунта, API-ключей и внешних библиотек.

## Что сделано
- Переключение русского и английского интерфейса.
- Три программы: спина и офис, кардио, силовая. В каталоге 45 упражнений (по 15 в каждой), у каждого анимация.
- Каждый день стабильно выбираются 4 упражнения из выбранной программы; набор дня фиксируется и не повторяет вчерашний.
- Уровень подготовки (начинающий / средний / продвинутый): выбирается при первом запуске, меняется в шапке. Влияет на число подходов, повторов или секунд и на время отдыха.
- Подходы отмечаются по одному; после подхода запускается таймер отдыха, для упражнений «на время» есть таймер подхода.
- Упражнения с пометкой «Сложное» (`hard: true` в каталоге) выпадают как обычные, но в подсказке есть кнопка «Пропустить (засчитается)».
- Необязательное напоминание о перерыве (выключено по умолчанию, интервал 30/45/60/90 мин, тишина с 22:00 до 08:00). Работает, пока сайт открыт, в том числе в фоновой вкладке: без собственного сервера браузер не может показывать уведомления закрытому сайту.
- Тёмная тема (тумблер в шапке).
- Виджет воды с анимированным стаканом.
- Прогресс, вода, уровень и выбранная программа сохраняются в `localStorage`.
- Service Worker для офлайн-работы.
- Нет внешних запросов; приложение не передаёт данные на сервер.

## Анимации упражнений

Все рисунки сгенерированы кодом (исходники — в папке `fitstudent-gifs/generator`), сторонних иллюстраций нет, атрибуция не требуется.
- `svg/{id}.svg` — лёгкая векторная анимация (основной вариант, кэшируется для офлайна).
- `gifs/{id}.gif` — запасной вариант, если SVG не загрузился.

## Как поменять иконку и логотип

Редактируйте только `brand-config.js`:
- `logoUrl` — путь к вашей иконке.
- `logoFallback` — эмодзи, если картинка не загрузится.
- `logoSize` — размер логотипа в шапке.
- `themeColor` / `bgColor` — цвета.
- `brandName` / `brandNameAccent` / `brandTagline` — текст бренда.

## Как устроен каталог упражнений

Файл `exercise-bank.js` содержит `window.FIT_EXERCISES` с ключами `back`, `cardio`, `strength`. У упражнения: `id`, `icon`, `name`, `focus`, `description`, `safety` (ru/en), `svg`, `gif` и блок `work`:

```js
work: {
  unit: 'reps',            // 'reps' — повторения, 'sec' — секунды (работа или удержание)
  side: false,             // true — «на каждую сторону/ногу»
  hold: 0,                 // удержание в секундах на повтор (для unit: 'reps')
  levels: {                // [подходы, повторы или секунды]
    beginner: [2, 6], intermediate: [3, 10], advanced: [4, 15]
  }
}
```

Чтобы добавить упражнение, положите `svg/{id}.svg` (и по желанию `gifs/{id}.gif`), добавьте объект в нужную программу и внесите `id` в список `EXERCISE_IDS` в `sw.js`. Время отдыха между подходами задаётся в `REST_SECONDS` в `script.js`.

## Как запустить

### Быстрый просмотр
Откройте `index.html` в браузере. Service Worker работает только через `localhost` или HTTPS.

### Полный режим с офлайн-кэшем
1. Установите Python 3.
2. `python -m http.server 8000`
3. Откройте `http://localhost:8000`.

Для публикации разместите папку на статическом хостинге с HTTPS (GitHub Pages и т.п.). При обновлении файлов меняйте `CACHE_NAME` в `sw.js`.
